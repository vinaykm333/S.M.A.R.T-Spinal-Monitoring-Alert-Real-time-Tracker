# S.M.A.R.T-Spinal-Monitoring-Alert-Real-time-Tracker
S.M.A.R.T. is a standalone Edge-AI system designed for paper-based study environments. Built on Raspberry Pi, OpenCV, and MediaPipe, it tracks real-time neck posture ($>30^\circ$) and fatigue ($\text{EAR} &lt; 0.2$). It delivers non-intrusive LED and audio alerts without requiring active laptops or wearables.
